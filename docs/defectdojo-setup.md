# DefectDojo Setup - TicketFlow Guardian

## Purpose

DefectDojo is used as the central server for collecting and reviewing security findings generated by TicketFlow security tooling.

## Local deployment

The TicketFlow development environment uses the official DefectDojo source repository as a local deployment source.

The upstream DefectDojo repository is kept locally under:

`defectdojo/django-DefectDojo/`

The upstream repository is not vendored into the TicketFlow repository.

## Services

The local DefectDojo deployment runs through Docker Compose and includes the DefectDojo application, PostgreSQL, Valkey, Celery workers/beat, and nginx.

The local web interface is available at:

`http://localhost:8081`

This port is intentionally local to the development machine and is not exposed publicly.

TicketFlow's Keycloak remains separate on:

`http://localhost:8080`

## Configuration and secrets

DefectDojo configuration is stored in the local `.env` file inside the upstream DefectDojo clone.

The following values are required locally:

- `DD_SECRET_KEY`
- `DD_CREDENTIAL_AES_256_KEY`
- `DD_PORT`

Secret values must never be committed to Git.

The local `.env` file is ignored by the DefectDojo repository, and the TicketFlow repository ignores the entire local `defectdojo/` directory.

## Initial setup

From the local DefectDojo repository:

1. Configure the required environment variables in `.env`.
2. Start the DefectDojo Docker Compose deployment.
3. Verify that the DefectDojo containers are running.
4. Open the local dashboard at `http://localhost:8081`.
5. Use the configured DefectDojo administrator account for administration.

## Security requirements

- Never commit `.env`.
- Never commit generated DefectDojo credentials or webhook secrets.
- Never commit the upstream DefectDojo source tree into TicketFlow.
- Do not expose the local DefectDojo port publicly.
- Production/shared deployment must use appropriately managed secrets and access controls.

## Validation

The local deployment was validated by confirming:

- DefectDojo containers start successfully.
- PostgreSQL and Valkey services are available.
- DefectDojo initialization completes successfully.
- The DefectDojo dashboard is accessible at `http://localhost:8081`.
- The DefectDojo administrator password was changed from the generated initial password.
- Secret configuration is stored locally and excluded from Git.
